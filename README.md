## Introduction

I'm **Doan Trung Kien**, a **Java Backend Engineer** based in Vietnam. I build backend services and asynchronous workflows, with a focus on maintainable code, reliable APIs, and performance.

I work with Java, Spring Boot, and Vert.x, verify behavior through automated tests, and optimize services with Redis caching and SQL query tuning. My interests include **distributed systems and event-driven architecture**.
